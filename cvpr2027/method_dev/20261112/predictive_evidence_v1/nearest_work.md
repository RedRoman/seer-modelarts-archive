# Predictive temporal evidence: nearest-work audit

Date: 2026-11-12. Scope: primary papers, author project pages/repos; literature and code reading only. No model execution, image scoring, target inspection, new cache, or changes to frozen experiments. This is an architecture decision note, not paper prose or a novelty certificate.

## Decision

**Keep only as a falsifiable mechanism candidate, not yet a claimed module contribution.** Reusing a pretrained JEPA predictor, using its prediction error as an external critic, error-guided intervention/fusion, response-difference contribution selection, and preserving an anchor each have close precedents below. A head that concatenates these scores and predicts transport weights would still look like a combination of known parts.

The narrower question worth testing is whether **removing a real temporal donor before contextual encoding changes prediction of a fixed, observable withheld region in a way that predicts the donor's incremental pixel-restoration utility**, beyond descriptor similarity, flow/photometric consistency, raw surprise, and a matched learned gate. The resulting action must be an explicitly constrained transport of observed candidate values around the frozen spatial base. This is a candidate distinction from the inspected works, not evidence of priority or sufficient novelty. A new operator/invariance or a reproducible mechanism advantage is still missing.

## What has not been established by this search

I did not verify an identical LLVE implementation combining a released native pretrained masked predictor, donor-wise pre-encoder temporal interventions, fixed observable latent targets, and constrained transport of real RGB candidates around a frozen spatial base. That bounded observation is **not** an absence proof. This quick audit is not exhaustive across restoration, burst photography, attribution, or conditional-information estimation. The strongest collisions are mechanism-level rather than identical-task matches.

Searching for masked predictive residuals also returns ordinary anomaly/surprise evaluation and diffusion generation guidance. Neither makes native latent residual a calibrated restoration risk. [Hristov et al., When Does Latent Prediction Error Support Physical Surprise Claims in Video World Models?, 2026](https://arxiv.org/abs/2611.01815) specifically studies appearance/motion/prediction-difficulty confounds. Its conclusions concern its physics settings; use it to motivate controlled score validation, not as a theorem that restoration must fail or as a new negative-results paper direction.

## Minimal concrete mechanism and controls before a novelty claim

Let `C` be visible context tokens, `H` a fixed withheld target region, `P` the matched pretrained predictor, and `z_H` the **same observable target representation** for every donor intervention. Define `L(C,H) = d(P(E_C(x), H), z_H)` and a leave-one-donor effect `Delta_d = L(C\d,H) - L(C,H)`. Positive `Delta_d` means the donor helped predict this particular observable target under this model/context. It does not prove clean-pixel usefulness, formal causality, uniqueness, or independent information.

1. **Real masking, not cached-feature deletion.** Official [V-JEPA2 encoder code](https://github.com/facebookresearch/vjepa2/blob/main/src/models/vision_transformer.py) applies `apply_masks` after patch embedding and before transformer blocks. Dropping a donor from already full-context-encoded descriptors leaves its information in the retained tokens. Respect the actual tubelet size; a two-frame tubelet can mix a supposedly excluded frame before attention. Keep positions/time coordinates fixed and remove all affected tubelets.
2. **Fixed evaluator.** Specify which input supplies `z_H` (low-light observation or frozen spatial base), its target-encoder context, normalization and distance. Hold it fixed across interventions. The critic target is observable and noisy, not clean GT. If excluded donor information is allowed into that fixed target representation, document the scope and add a target-local/context-controlled alternative; otherwise “independent evidence” is overstated.
3. **Matched checkpoint first.** Strict-load the pretrained encoder **and predictor** with matching architecture/normalization/mask conventions and record hashes. An encoder-only distilled checkpoint plus a random or mismatched predictor does not instantiate this hypothesis. Loading only the intersection with `strict=False` is not evidence of a pretrained critic.
4. **Test incremental utility, not raw responsiveness.** On source FIT only, check whether donor ordering predicts the *incremental* restoration benefit relative to the same frozen base and the same fixed candidate construction. Compare native surprise, descriptor similarity, flow/photometric confidence, a descriptor-conditioned matched gate, and donor-removal score. Raw effect magnitude can reward corruptions; low error can reward static copying/blur.
5. **Separate contribution from interactions.** Leave-one-out effects depend on other donors. Duplicate donors, redundant same-frame copies, donor permutations, time reversal, controlled temporal mismatch, noise and occlusion need explicit controls. Duplication should not manufacture extra independent evidence or change total transport solely through multiplicity. A marginal score alone is not a Shapley/conditional-mutual-information estimator.
6. **Make transport constrain an action.** Predeclare how critic evidence admits, rejects or caps an aligned donor's observed-value displacement from the HVI base; prove exact base recovery for zero transport. Compare with the identical transport operator driven by ordinary confidence and with score-shuffled controls. Exact base recovery is an algebraic identity, not a monotonic PSNR guarantee. No RGB decoder is an architectural restriction, not sufficient novelty by itself (kernel prediction/fusion already does this).
7. **A specific stop rule.** If the native predictor is unavailable, or donor effects fail to predict source-only incremental utility beyond these controls, do not promote a renamed generic MLP gate to a novel core module. Retain it, if useful, as a known-mechanism baseline. No target selection or tuning is justified by this literature audit.

## Recommendation to the architecture owner

The mechanism has a defensible *question*, but the current description still lacks a distinct transport/credit operator and evidence that pretrained prediction has a different causal role from learned confidence. The most valuable next artifact is a frozen source-only mechanism specification with the actual checkpoint and masking implementation, plus matched contribution controls; not a new name or a “first foundation critic” claim. In particular, avoid broad novelty claims already covered by WMReward, predictor transfer, Fovea-JEPA, ANCHOR and response-difference prototype selection.
