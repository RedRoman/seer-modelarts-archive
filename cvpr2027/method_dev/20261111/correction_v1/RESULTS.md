# BVI 训练纠正候选：可行性结果

固定 BVI 域内 E12 full 模型，48 个 TRAIN 序列、24 场景各两种照度，每序列一个预先固定的16帧/crop256片段。
一次恢复输出供所有候选；RAFT只读取恢复RGB，GT仅生成风险目标和本表oracle。

| 候选 | 连续 RGB MSE | 相对 base 的 MSE 降幅 |
|---|---:|---:|
| base | 0.001692703293 | +0.00000% |
| 过去邻帧 | 0.001736688018 | -2.59849% |
| 未来邻帧 | 0.001820424010 | -7.54537% |
| 固定平均 | 0.001639313587 | +3.15411% |
| GT辅助受约束 oracle | 0.001334529793 | +21.15985% |

Oracle仅表示这两个固定纠正方向的凸组合空间，不是已学得性能。单独邻帧均变差，固定平均有小幅收益，剩余空间需由不读取GT的选择器实际学出。
训练缓存约3.95GB留在31051本地/cache；此目录只归档摘要、来源、源码/缓存哈希清单与CPU检查，不存图像或模型大权重。
所有48缓存重新核验SHA，基础模型state前后相同。

下一实验在这24个训练场景内固定分18拟合/6内部留出；base可能已见过全部24场景，因此它只检验新增选择器的可学习性。
三个同容量网络使用同初值/同采样计划，各1000步；比较风险监督、直接MSE、仅按拟合集base均值MSE缩放loss的直接MSE。
拟合归一化仅使用18场景；三个方法全训完后统一评价最终模型，不选最佳checkpoint。
正式 BVI VAL16 将另用独立入口评价全部三个最终模型，测试图像保持未读。
