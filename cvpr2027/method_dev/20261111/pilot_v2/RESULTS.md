# Pilot v2：冻结基础模型的融合模块筛选

600 个 optimizer steps、accum=1，仅训练 30,724 个新融合参数，基础模型全部冻结。Local 和 prior 各训练 seed 0，使用相同初始参数、样本及增强计划；在 SDSD VAL16（8 个场景）评估 0／200／400／600 步。没有新增 baseline 续训组；对照是各组固定的 step0 输出。没有读取 TEST 图像或指标。

终点 PSNR-Y 相对起点：local **+0.00415 dB**（scene 95% CI **[−0.01199,+0.02391]**），prior **+0.00263 dB**（**[−0.00849,+0.01643]**）。Prior−local 为 **−0.00152 dB**（**[−0.00797,+0.00437]**）。本轮没有显示实质或稳定的像素恢复收益，也没有显示 foundation 对应引导优于局部融合。

Prior 相对起点的 LPIPS 为 −0.00010250，其未校正场景区间 [−0.00018856,−0.00002280] 不跨零；local 为 −0.00012569，区间跨零。两组的 tLP gap 都略降，但这些很小的描述信号不能替代 PSNR 证据或支持 SOTA/稳定性结论。基础参数冻结避免了 v1 的续训漂移，却没有证明插入模块本身能带来有竞争力的收益。
