# Pilot v1：SDSD 验证集的匹配续训结果

这是单 seed 的方法开发结果：训练 400 个 optimizer steps、accum=1，评估冻结 VAL16（8 个场景）在 0／200／400 步的表现。没有读取 TEST 指标或测试帧，也不构成 SOTA 或训练 seed 稳定性证据。

Local 相对同预算 baseline 的 PSNR-Y 均值为 **+0.1142 dB**，但 scene bootstrap 95% 区间为 **[−0.4816, +0.9756] dB**，仅 6/16 序列更好；LPIPS 差值区间同样跨零。这是值得后续隔离验证的弱信号，不能表述为稳定提升。Prior 的 PSNR-Y 终点比 baseline 低 0.6487 dB、比 local 低 0.7629 dB；本轮没有显示额外语义对应引导的收益。

三组在第 200 步均低于起点；第 400 步 baseline 和 local 分别回升至起点以上 +0.3298、+0.4440 dB，prior 仍为 −0.3189 dB。Local 的平均收益有明显场景异质性；由于三组同时微调基础像素模型，这些组间差值不能直接作为某个融合消息的因果增益标签。

## 溯源与统计方法

- 三组的 checkpoint 输入 SHA、基础像素 state SHA、完整样本计划 SHA、first-batch SHA 和 source manifest 完全一致；local/prior 的 fusion 初始 state SHA 完全一致。
- 实算了各份 `data_plan.json` 的 SHA，并从私有 NumPy RNG 逐项重建全部 400 个样本及 augmentation seed；检查完整训练名单、split SHA、训练预算/LR 与配置。
- 三组 step0 的每序列 PSNR-Y、PSNR-RGB、LPIPS、tLP gap 最大差均为 **0**；所有组、所有评估步的 GT tLP 最大差也为 **0**。
- 每份报告必须包含相同的冻结 VAL16 名称、正确 variant/step/split、有限数值；汇总均值和逐序列 tLP gap 必须与原始行一致。
- 原源码固定为 `8a9dcfa84a3466cf2dc567903a39b6ba1210bb8e`，对六个记录文件用 `git show` 读取提交字节并核验 SHA。当前工作树 trainer 的 v2 修改不参与 v1 核验。
- NumPy `default_rng(0)`：先生成 10,000 组 16-sequence draws，再生成 10,000 组 8-scene draws；所有 metric、step、contrast 共用这两组抽样索引。场景去掉末尾 `_2`，保留 indoor/outdoor 前缀。
- 主估计是序列加权均值。Scene replicate 是抽中场景的差值总和除以序列总数；这里每个场景含两个序列。区间条件于一个已训练 seed，不估计重复训练的不确定性。
- 本分析读取记录中的 checkpoint/first-batch SHA 进行一致性比较，没有再次打开模型权重或数据图像来重新计算这两类内容哈希。

## 复算

在仓库根目录运行；`--runs` 指向含 `baseline_s0`、`local_s0`、`prior_s0` 的已下载原始结果目录。每组需包含 provenance、data_plan 及三步的 VAL JSON。输出路径必须尚不存在。

```sh
python3 cvpr2027/method_dev/20261111/analyze_pilots.py \
  --runs cvpr2027/method_dev/20261111/pilot_v1/runs \
  --step 400 \
  --code-revision 8a9dcfa84a3466cf2dc567903a39b6ba1210bb8e \
  --out /tmp/pilot_v1_recomputed.json
```

本次 `analysis.json` SHA-256：`34508294d5fe900f18e03f05fe2b21c2a281b069c6ada23ffff57febd35badac`。结果文件记录了每个输入文件的路径与 SHA、分析器 SHA、NumPy 版本以及完整解析后的 Git revision。
