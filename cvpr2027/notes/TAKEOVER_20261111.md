## 完成的纠正

1. **Random identity。** 训练使用固定初始化 seed 1234，旧评测没有。
   正确重评覆盖全部 39 test 序列。初始参数近似 checksum 与日志相符，
   末位差源于旧 NPU 不支持 double 而自动降为 float 的累加。
   这不是完整编码器的 bitwise 哈希证明。预训练与 random 的 PSNR 差不显著，
   LPIPS 差有利，但只有一个 random 训练 seed。
2. **E26 投影。** 原 runner 使用 generic evaluator，没有恢复训练时的
   `global_rank`。两 seed 在推理也应用同一保存基底后重评。
   对匹配的 pretrained seeds 0/1，两指标均未检出差异，seed 方向不同。
   原显著训练期惩罚撤回；未检出差异不证明等效或计算加速。
3. **统计与度量。** tLP 与 GT 的距离统一为绝对值，且在各 arm seed 平均后计算。
   逐 seed 的方向检查也用相同定义。缺失指标按共同有效名字联合过滤。
   时间损失负面判定保持，点估计已修正。
4. **机制边界。** clip PCA 保留完整均值、基底和每 token 的投影坐标，
   固定 PCA 则换成训练集均值与基底。原差值并没有隔离“基底是否自适应”。
   VAL16 的六条件探索性控制在结果之前写入 Amendment 21；现已完成两 seed、
   16 序列/8 场景。均值有贡献，且保留 clip 均值时自适应方向优于固定方向；
   rank-4 与完整 token 的差异仍未定。完整来源与统计见
   `MEAN_BASIS_VAL_20261111.md`，不把探索性 VAL 控制当作 test 证据。
5. **不独立的帧率/重复拍摄。** post-hoc scene-cluster bootstrap 使用原 split
   builder 的场景分组，维持主要判定；它没有被追认成原预注册检验。
6. **E18 KV/layers。** hybrid seeds 0/1 与 all-layers 实际 seed 2 均完成
   39 test 序列重评。hybrid 的 LPIPS 两 seed 改善，PSNR 未定；all-layers
   原 21.568 dB 错评撤回，修正后 25.139 dB，但对照差异未定，且单 seed、
   训练硬件不同。其时间诊断有变差，不把单项有利结果泛化为架构优势。
